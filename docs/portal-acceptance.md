## 3. 本轮定量观察（不凭空给性能结论）

- 遥测（归档轮）：基线（同轮无负载复测）**301 帧/15s**（20 帧/s，max 82ms）、负载（同步+2 页轮询）**400 帧/20s**（20 帧/s，max 82ms）——**无劣化**；真实 50Hz 固件数值待实机。本行『基线』为**同轮无负载复测**（更早轮次为 300/401 帧，差异属窗口边界 ±1 帧）；阶段 0 基线文档未记录遥测帧率/延迟数字。该用例另有前提断言：负载轮 bitable +12、基线段 +0。
- 请求放大（收尾轮）：3 页面 15s 轮询 + 1 次手动刷新 → bitable 请求增量 **12**，**恰等于一轮完整同步的成本**（当轮口径 4 表 × (字段 + 记录 + 记录链接 batch_get) = 12 次请求；**2026-09-12 加入第 5 张同步表 members 后，一轮成本 = 5 表 × 3 = 15 次**），不随浏览人数增长；该用例 `PORTAL_SYNC_INTERVAL=3600`，15s 观察窗内不存在定时轮，因此 12 全部来自那次手动刷新轮。**断言已由区间 4≤增量≤12 收紧为 10≤增量≤14（**2026-09-12 起随第 5 表加入放宽为 13≤增量≤17**）**，并加页面侧对照：同期 3 个页面共发本地 API 请求 **63** 次（轮询打本地、不上飞书）。**本用例仍未做 1 页面对照组**（待强化项）；3 页同刻手动刷新：本轮增量 12、1 轮 + 合并/限频反馈（`merged≥1` 硬断言）。
- 同步失败保持旧版：断网注入后版本不变、错误类别 network、旧数据可读。
- 定时：5s 间隔 25s 窗口 2 轮成功（生产 60s；此处以 5s 间隔做**路径等价**验证，**非 60s 实测**）。
