## 2. 字段清单

| 语义键 | 飞书列名 | 类型 | 说明 |
| --- | --- | --- | --- |
| `name` | 采购物资名称 | 文本 | 必填；缺失计入数据质量异常并排除出统计 |
| `groups` | 申请组别 | 多选 | 五组：机械/硬件/电控/算法/运营 |
| `link` | 购物链接 | 文本 | 缺协议自动补 `https://` |
| `purpose` | 用途说明 | 文本 | 采购用途 |
| `attachments` | 图片补充 | 附件 | 实物图等；**仅图片**，≤10MB/张 |
| `leader_approval` | 组长批复 | 复选 | **唯一受限列：仅组长可改** |
| `purchased` | 已采购 | 复选 | 全员可改 |
| `season` | 赛季 | 单选 | 门户顶部按赛季切换/汇总；如 `2027赛季` |

| `quantity` | 数量 | 数字 | 整数 |

| `invoice_files` | 发票文件 | 附件 | PDF 或图片，≤20MB/份 |

### 2.1 采购编号规则

`<赛季数字>-<一级分类缩写>-<四位流水>`，例如 `2027-BZJ-0001`。

- 一级分类缩写：电机 `DJ`、标准件 `BZJ`、加工件 `JGJ`、电子元器件 `DZ`、
  线材接插件 `XC`、工具耗材 `GJ`、其他 `QT`（未知分类退化为 `QT`）。
- 流水号取**飞书实时数据**里同前缀的最大号 +1（不吃快照滞后，避免连开两条重号）；
  读不到飞书时**宁可不填编号**，也不写重复编号。
- 想要手填编号：在新建/编辑表单的「采购编号」里直接填写，非空即不自动生成。
- 什么时候取号（2026-10-21 修正）：**新建和编辑都会取号**——记录还没有编号、且赛季与
  一级分类都有值时自动补上；已有编号的记录改分类也不重新取号。此前只在新建时取号，
  先提交申请、之后才补分类的记录永远没有编号。缺赛季或一级分类时写入照常成功，
  通知里说明「补上后自动生成」；取到号时通知里带上编号。
- 新建采购申请时赛季默认取页面当前筛选的赛季；没筛选就取当前赛季（每年 9 月起算
  下一赛季，如 2026-10 → `2027赛季`）。
- 修正之前留下的无编号记录：补填赛季 / 一级分类，或对它做任意一次修改（如勾选「已采购」），
  只要两者齐全就会自动补号。

### 2.2 总价为什么是公式

`总价（元）` 由飞书公式计算（`property.formula_expression` 为显式字段引用）。
好处是**在飞书里直接改单价/数量也自动联动**，门户无需回写。

注意：飞书**不接受按列名书写的公式引用**（实测写成 `单价（元）*数量` 时该列不参与
计算、记录读回时字段缺失），必须写成
`bitable::$table[<table_id>].$field[<field_id>]*...`——`ensure_formula()` 会按真实
`field_id` 生成，重跑脚本即自愈。

## 3. 权限口径

- 除 `组长批复` 外，**全部字段（含金额、发票）全员可改**（维护者选定的口径）。
- 新建：成员即可；`组长批复` 只有组长能在新建时勾选。
- 删除：仅组长（破坏性操作，与事项/日程口径一致）。
- 前端按身份显隐按钮，**判定以服务端为准**（`app/portal/api.py` 的 `_procurement_gate`）。

## 4. 附件上传

`POST /api/portal/write/procurement/{record_id}/attachments?column=<image|invoice>`

| column | 目标列 | 允许格式 | 上限 |
| --- | --- | --- | --- |
| `image`（默认） | 图片补充 | png/jpg/jpeg/gif/webp/bmp | 10MB（`PROCURE_ATTACH_MAX_MB`） |
| `invoice` | 发票文件 | 上述图片 + pdf | 20MB（`PROCURE_INVOICE_MAX_MB`） |

上传流程：先 `drive/v1/medias/upload_all` 拿 `file_token`，再与**该记录该列既有附件合并**
后整列写回——不会覆盖别人刚传的文件。同一次新建表单里选的多份附件按各自 `column` 逐份上传。

## 5. 门户侧行为

- **筛选**：申请组别（chips）+ 赛季 / 一级分类 / 二级分类 / 开票状态（下拉）+ 关键词
  （匹配物资名称、采购编号、用途说明）；二级分类候选随一级分类联动收窄。
- **汇总**：列表上方显示当前筛选口径下的「条数 · 合计金额」。
- **下拉选项自适应**：接口在 `options` 里返回「常量清单 ∪ 快照中实际出现的值」，
  所以维护者在飞书里**新增选项后门户无需改代码**即可选到；历史值即使已从飞书选项里
  删掉，也仍能筛得到（下拉里显示为「xxx（已从飞书选项移除）」）。
- **未知值不当异常**：赛季/分类用直通字符串，不做白名单校验，避免飞书新选项被误报成
  数据质量异常。质量异常只保留原有口径（缺物资名称、申请组别未知值、日期非法）。
